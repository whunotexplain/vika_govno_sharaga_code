# PyQt6 Shop Example

Учебное desktop-приложение магазина на Python 3.13, PyQt6, PostgreSQL, SQLAlchemy 2.0 и Pandas.

## Возможности
- каталог товаров, поиск по названию;
- фильтрация по категории и диапазону цен;
- сортировка по названию и цене;
- окно подробной информации о товаре;
- корзина в памяти приложения;
- оформление заказов и хранение состава заказа в PostgreSQL;
- уменьшение остатков в одной транзакции;
- импорт Excel с очисткой данных через Pandas.

## Структура
- main.py — точка входа;
- DB_Units — подключение, ORM-модели и репозитории;
- UI_Windows — главное окно, карточка товара и корзина;
- Data_Processing — чтение, очистка и загрузка Excel;
- Excel_Tables — входной файл товаров.

## Установка PostgreSQL
Установи PostgreSQL, запусти сервер и создай базу:
    CREATE DATABASE shop_db;

## Установка Python и зависимостей (PowerShell)
    py -3.13 -m venv .venv
    .venv\Scripts\activate
    python -m pip install --upgrade pip
    pip install -r requirements.txt

Скопируй .env.example в .env и укажи параметры подключения:
    DB_HOST=localhost
    DB_PORT=5432
    DB_NAME=shop_db
    DB_USER=postgres
    DB_PASSWORD=твой_пароль

Не публикуй .env: он содержит пароль.

## Запуск
    python main.py

При первом запуске приложение проверит соединение, создаст таблицы и сгенерирует демонстрационный products.xlsx. Если каталог пуст, товары импортируются из Excel.

## Архитектура и теория

### Подключение к БД
Connection создаёт SQLAlchemy Engine и фабрику Session. Engine управляет соединениями с PostgreSQL, Session представляет рабочую сессию. Каждую операцию с БД следует выполнять в отдельной сессии.

### ORM
Product, Order и OrderItem — ORM-модели, описывающие таблицы. Order связан с OrderItem отношением один-ко-многим. В строке заказа сохраняются название и цена на момент покупки, поэтому история не зависит от последующих изменений каталога.

### Repository
ProductRepository отделяет SQL-запросы от интерфейса. Поиск, фильтрация и сортировка выполняются на стороне PostgreSQL, а не после загрузки всего каталога в Python.

### PyQt6
QMainWindow — главное окно. Layout управляет размещением элементов. Сигналы textChanged, currentTextChanged и clicked соединяются с методами через connect(). Так интерфейс реагирует на ввод и нажатия пользователя.

### Корзина и транзакции
Корзина — словарь Python в памяти. При оформлении заказа создаётся Order и его OrderItem, затем уменьшается складской остаток. Все изменения сохраняются одним commit. Если возникает ошибка, rollback отменяет изменения, чтобы заказ не сохранился частично.

### Pandas и Excel
read_products читает XLSX, проверяет обязательные столбцы, удаляет пустые и повторяющиеся строки, приводит цену и остаток к числовым типам. data_loader переносит очищенные данные в PostgreSQL. Excel используется как источник импорта, PostgreSQL — как основное хранилище.

## Учебные ограничения
Это учебный пример, а не production-магазин. Для реального сервиса понадобятся авторизация, роли, миграции Alembic, тесты, логирование, резервные копии и защита от конкурентного изменения остатков.
