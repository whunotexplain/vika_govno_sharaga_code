# Магазин спортивной одежды

## Запуск базы PostgreSQL
1. Создайте базу данных `sportswear_shop`.
2. Откройте Query Tool в pgAdmin для этой базы.
3. Выполните весь файл `schema.sql`.
4. Скопируйте `.env.example` в `.env` и укажите пароль PostgreSQL.
5. Установите зависимости: `pip install -r requirements.txt`.
6. Запустите приложение: `python main.py`.

Демо-вход: `demo` / `demo123`.

## Важно
Папка `resources/images/` предназначена для фотографий товаров. Положите туда изображения
и укажите соответствующие пути в таблице `products` (либо оставьте пустыми — приложение
покажет надпись «Нет фото»). Не храните настоящий пароль БД в репозитории.
В учебном примере пароли клиентов сравниваются в открытом виде для совместимости с исходным
кодом; для реального проекта нужно перейти на хэширование паролей.
